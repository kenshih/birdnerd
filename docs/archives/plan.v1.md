# BirdNerd — Roadmap archive v1 (Phases 1–20)

This consolidated archive records the completed roadmap through Phase 20.
The active roadmap is [plan.md](../plan.md); shipped release detail is in the
[changelog](../../CHANGELOG.md) and the applicable specifications.

---

## Completed phase summaries

| Phase | Outcome |
|-------|---------|
| 1 | MVP offline data capture: installable PWA, species entry, sessions, and IndexedDB-backed bird records. |
| 2 | GitHub Pages deployment, app branding and installation guidance, plus CSV export/import. |
| 3 | Full BBL species list with scientific names and autocomplete. |
| 4 | Navigation shell, module routing, export screen, and placeholders for future modules. |
| 5 | Curated code tables and the remaining core banding-form fields. |
| 6 | Location and net management, seeded station data, and location-backed session selection. |
| 7 | People, bander roles, and roster data. |
| 8 | Form information architecture, searchable inputs, and consistent page navigation. |
| 9 | Versioned JSON backup and restore for managed local data. |
| 10 | Full session editing, session detail, roster, and cascade behavior. |
| 11 | Weather fields, net effort, net-hours, and net lifecycle support. |
| 12 | Non-blocking, pure validation warnings across the banding form. |
| 13a | Band inventory, search and selection, atomic band deployment, and foreign recaptures. |
| 13b | Recapture-condition and replacement-band fields. |
| 14 | Photo records, mobile capture, local storage, and share/download handling. |
| 14.5 | Data, PWA-status, documentation, and plan-migration cleanup. |
| 15 | Agency exports: MAPS master-list and BBL upload formats. |
| 15.5 | Field fixes and shared styling/code-table refactors. |
| 16 | PWA update experience, deployment hardening, and visible app version. |
| 17 | Error boundary and fallback UI. |
| 18 | Initial shared card and style conventions; remaining component work deferred. |
| 19 | Species and disposition validation enhancements. |
| 20 | Band-history timeline, foreign-band flow, and inventory enhancements. |
